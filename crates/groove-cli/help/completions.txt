EXAMPLES:
  groove completions bash > groove.bash
  source groove.bash
  groove completions zsh > _groove
  groove completions fish > groove.fish
  groove --json completions bash

Prints a script; does not install it or change shell startup files. Redirecting
stdout overwrites the destination file. Output is shell code by default. Do not
add --json when generating a file to source: it wraps the script in JSON for tools.

ZSH SETUP (including Oh My Zsh):
  mkdir -p ~/.zsh/completions
  groove completions zsh > ~/.zsh/completions/_groove

Add this line once to ~/.zshrc (or $ZDOTDIR/.zshrc if configured), before your
existing compinit call or before source $ZSH/oh-my-zsh.sh:
  fpath=("$HOME/.zsh/completions" $fpath)

Oh My Zsh initializes completions itself. Only if your configuration does not
already initialize them, add these lines after the fpath line:
  autoload -Uz compinit
  compinit

Open a new terminal, type groove followed by a space and press Tab. In that Zsh
session, print -r -- ${_comps[groove]} should print _groove.

BASH SETUP:
  mkdir -p ~/.local/share/bash-completion/completions
  groove completions bash > ~/.local/share/bash-completion/completions/groove
Add once to ~/.bashrc:
  source "$HOME/.local/share/bash-completion/completions/groove"
Ensure your Bash login startup file loads ~/.bashrc when using a login shell.
Open a new terminal; complete -p groove should show its registered function.

FISH SETUP:
  mkdir -p ~/.config/fish/completions
  groove completions fish > ~/.config/fish/completions/groove.fish
If XDG_CONFIG_HOME is customized, use $XDG_CONFIG_HOME/fish/completions instead.
Fish loads the file automatically. Open a new terminal and press Tab after
groove and a space; complete -C 'groove ' should list suggestions.

Inspect existing startup configuration before editing it; preserve customizations
and avoid duplicate entries. Verify in the intended interactive shell, which may
differ from an agent's execution shell. PowerShell and Elvish scripts can be
loaded using their shell's normal mechanism.

Completes commands, options and fixed choices, not live task names or lease IDs.
No repository or valid user configuration is required. Regenerate after upgrading.
With --json, the script is result.text in the normal single
JSON response; extract that field before loading it into your shell.
