EXAMPLES:
  groove list
  groove list -p frontend
  groove list --sort acquired --limit 20

Lists active reservations across every pool, including ones left by interrupted
commands. Human output includes a POOL column. -p/--pool filters to one pool.
Use pool show [NAME] for the slot table and pool show --details for Git status.
Observations never prove ownership or that writers have stopped.
Corrupt ready-slot metadata is reported as unhealthy with its failure.

Returns at most 50 entries by default, ordered by task label. Use --limit N to
change the page size, --offset N to continue, or --unlimited for the complete list.
JSON includes pagination.total, offset, limit (null with --unlimited) and next_offset
(null at the end). An empty page does not mean the pool has no reservations.
Metadata is still enumerated.
Concurrent changes can shift offset pages; observations never grant ownership.
--sort task orders labels lexicographically, --sort pool groups by pool, and
--sort acquired orders by acquisition time (newest first by default).
--order asc|desc applies before pagination. Task and pool sorts default to asc.
