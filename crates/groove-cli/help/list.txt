EXAMPLES:
  groove list
  groove list --slots
  groove list --details

By default lists active reservations, including ones left by interrupted
commands. --slots lists slots with their status, reason and suggested next
action. --details adds bounded local Git status (staged, modified, untracked).
Observations never prove ownership or that writers have stopped.
Corrupt ready-slot metadata is reported as unhealthy with its failure.

Returns at most 50 entries by default, ordered by slot ID. Use --limit N to
change the page size, --offset N to continue, or --unlimited for the complete list.
JSON includes pagination.total, offset, limit (null with --unlimited) and next_offset
(null at the end). An empty page does not mean the pool has no reservations.
Metadata is still enumerated; --details checks Git status for all slots.
Concurrent changes can shift offset pages; observations never grant ownership.
--sort task orders labels lexicographically, with unlabelled entries first and
slot ID breaking ties. --sort slot restores the default order.
--order asc (default) or --order desc applies to the sort key and slot-ID
tie-breaker before pagination. Descending task order puts unlabelled entries last.
