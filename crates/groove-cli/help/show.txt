EXAMPLES:
  groove show
  groove --pool default show --disk-usage
  groove show --task fix-parser
  groove show --lease-id UUID --details
  groove show --slot wt-0001

Without a selector, shows pool settings and every slot. With --task or
--lease-id, shows that reservation (or its release receipt) and its slot.
--details reads bounded local Git status (staged, modified, untracked); with a
selector, only that workspace is checked. Nothing contacts a remote.

--disk-usage adds workspace, cache, log and history sizes to the pool view;
it cannot be used with a reservation or slot selector. The scan includes ignored
files and can take time on large pools. Sizes are logical file bytes; shared Git
objects and snapshots are excluded. Combine with --details for Git status.
