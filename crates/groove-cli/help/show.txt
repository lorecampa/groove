RESERVATION is a task label or reservation UUID, searched across every pool.
When omitted, the current acquired workspace (including subdirectories) selects
its active reservation. --repo can select that workspace from elsewhere.
Show one reservation (or its release receipt) and its slot.
Historical reservation output includes active=false; successful inspection does
not prove an active assignment. Slots retain reservation history, marked with
reservation_active=false. Only active task labels appear in the current task column.
--details reads bounded local Git status only in the selected workspace. Busy
status is unavailable after at most two seconds of execution-lock contention.
Nothing contacts a remote. To inspect pool settings and all slots, use pool show.
