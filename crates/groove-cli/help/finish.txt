EXAMPLES:
  groove finish --task fix-parser
  groove finish --lease-id UUID --description 'parser fix'

Stop managed and external writers first. finish saves and pins a snapshot of
staged and working files, then releases the reservation. A snapshot failure
keeps the reservation protected. finish refuses with WORKSPACE_IN_USE while other
processes still use the workspace; --force skips that best-effort check (never a
running `groove exec`). The pinned snapshot survives slot reuse:
recover it with `groove snapshot restore ID --to PATH`.

Finish receipts make retries by lease ID safe after a lost response or slot reuse.
Parallel tasks wait for snapshot access up to --git-timeout-ms (default 120000).
A timeout keeps the reservation protected; retry with the same lease ID.
Nothing is pushed.
